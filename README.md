# Nuvriqo Ivanti Migration Assistant

Forge app for migrating Ivanti Neurons / Service Manager service definitions into Jira Service Management.

Current development version: **v6.2**.

The app currently supports Ivanti ROX/XML analysis, Jira field creation/reuse, work types, workflows and schemes, Jira screens and screen schemes, JSM request types, populated JSM Forms, conditional Form logic, migration health checks, automation migration analysis, workflow migration analysis, and a Migration Test & Validation Centre.

This repository is the canonical source for ongoing development and GitHub-based deployment.
