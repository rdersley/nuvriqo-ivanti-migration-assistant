# Ivanti Migration Assistant v5.1

## New: Environment Health Check

- Verifies Jira configuration access.
- Verifies status and workflow administration access.
- Validates the selected target project.
- Detects team-managed projects that cannot use workflow schemes.
- Checks whether the target project is empty and warns before scheme changes.
- Gives a clear Ready to build / Action required result.

The existing v5.0.2 idempotent Jira builder is unchanged.
