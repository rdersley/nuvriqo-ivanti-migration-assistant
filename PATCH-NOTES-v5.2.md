# v5.2 – Jira Screen Builder

- Creates or reuses Create, Edit and View screens.
- Adds standard and migrated custom fields to each screen.
- Creates or reuses a screen scheme.
- Creates or reuses an issue type screen scheme mapped to the migrated issue type.
- Can assign the issue type screen scheme to the selected company-managed project.
- Preserves v5.1 health checks and v5.0.2 idempotent Jira structure creation.
